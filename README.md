# MyoSync Food Catalog

MyoSync 標準食品辞書の配布用リポジトリです。

## 出典

文部科学省「日本食品標準成分表（八訂）増補2023年」から引用・加工（2026年3月27日正誤表対応資料）。

- https://www.mext.go.jp/a_menu/syokuhinseibun/mext_00001.html
- 利用・引用条件：https://www.mext.go.jp/a_menu/syokuhinseibun/index.htm

本辞書はMyoSync独自の選定・加工データであり、文部科学省の公式辞書ではありません。GI、吸収時定数、カフェイン、レシピ、汎用サプリメント等には推定値が含まれます。zero_filled_fields は欠測等のゼロ補完を示し、実測ゼロとは限りません。実製品の表示値とは異なる場合があります。医療判断用ではありません。

## 配布

manifest.json は最新辞書の情報を示します。catalogs/ 以下の公開済みバージョンは上書きせず、新バージョンを追加します。CSVはUTF-8 BOM付きです。v4はEAA、BCAA、L-ロイシンのタンパク質を100g当たり100gとした版です。

文部科学省の原資料の利用条件は上記公式ページを参照してください。独自加工部分の包括的なライセンスは未指定です。
